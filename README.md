# 阿瓦隆

可離線使用的阿瓦隆角色抽籤與任務紀錄網站，純 HTML／CSS／JavaScript，不需要安裝套件或連上外部服務。

## 使用方式

直接開啟 `index.html` 即可使用。

若要啟用可安裝的 PWA 與離線快取，請在此資料夾啟動本機伺服器：

```sh
python3 -m http.server 4173
```

接著開啟 `http://localhost:4173`。首次載入後，即使沒有網路也能繼續使用。

## 功能

- 三步驟設定：人數（5–10 人）→ 玩家名稱 → 角色與特殊規則
- 角色：梅林、派西維爾、刺客、莫甘娜、莫德雷德、奧伯倫，自動補齊忠臣與爪牙
- 特殊規則（可自由勾選）：
  - 湖中女神：第 2、3、4 局後查驗一位玩家的陣營
  - 蘭斯洛特：忠邪各一，第 3–5 局前翻忠誠牌，可能交換陣營
  - 王者之劍：持有者可秘密翻轉一張任務票
- 翻牌式身分揭示，依角色顯示正確情報，音效不洩漏陣營
- 組隊表決、秘密任務投票、7 人以上第四局雙失敗規則
- 隊長輪替、連續否決計數、刺客指認梅林、遊戲結束身分揭曉
- 自動存檔，重新整理後可繼續上一局
- 深色／淺色主題、音效開關、支援「減少動態效果」

## 檔案

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 頁面結構與圖示 |
| `styles.css` | 全息 HUD 科幻風格樣式 |
| `app.js` | 遊戲邏輯 |
| `sw.js` | 離線快取（更新內容時請調整 `CACHE_NAME`） |
| `manifest.webmanifest`、`icon.svg`、`*.png` | PWA 設定與圖示 |
