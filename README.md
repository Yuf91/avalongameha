# 亞瑟王的密令

可離線使用的阿瓦隆角色抽籤與任務紀錄網站，不需要安裝套件或連上外部服務。

## 使用方式

直接開啟 `index.html` 即可使用抽籤功能。

若要啟用可安裝的 PWA 與離線快取，請在此資料夾啟動本機伺服器：

```sh
python3 -m http.server 4173
```

接著開啟 `http://localhost:4173`。首次載入後，即使沒有網路也能繼續使用。

## 功能

- 支援 5–10 位玩家
- 自訂玩家名稱與特殊角色
- 自動補齊忠臣與爪牙
- 裝置傳遞與私密身分揭示
- 依角色顯示正確情報
- 五次任務人數及 7 人以上第四局雙失敗提示
- 任務結果、比分與隊長紀錄
